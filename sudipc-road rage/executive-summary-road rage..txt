Assignment Overview:
The purpose of the Road Rage project was to design and implement a simulation of vehicles moving around a map using object-oriented principles like inheritance, polymorphism, and abstraction. Each vehicle behaves differently based on rules defined by its class, and the simulation tracks how they move, collide, and revive over time. This assignment was mainly about understanding how to structure reusable and maintainable code through an abstract base class (AbstractVehicle) and multiple subclasses (Car, Truck, Bicycle, Taxi, Human, Atv) that define unique logic. It also involved writing and running JUnit tests to verify functionality, collisions, movement logic, and overall correctness of the simulation. 

Technical Impression:
To complete the assignment, I implemented each vehicle class by extending AbstractVehicle, making sure every one of them followed the specific terrain and traffic light rules. I also added proper Javadoc documentation for clarity and consistency. Writing the test files took some time, especially learning to use JUnit 5 correctly with assertions and setup methods.
One of the biggest challenges was handling IOExceptions when running RoadRageMain.java. The program couldn’t find city_map1.txt, which I later realized was because IntelliJ wasn't treating the main class as runnable. Understanding how Java’s file loading works within a project structure was frustrating at first. Another issue was making sure collision and revival logic worked properly without breaking other behaviors. Sometimes vehicles stayed dead forever due to incorrect poke() logic.
The project also tested patience with debugging. The inheritance hierarchy was powerful but tricky since small logic mistakes in AbstractVehicle affected every subclass. Despite that, I gained a better understanding of polymorphism and code reusability. I still feel more practice with debugging large multi-class projects would help.
